安装与进度接口文档

更新于 2026-11-26 · HTTP 协议与浏览器网页接口

网站提供目录和 CRX，浏览器负责下载、验证、权限确认与安装事务。本文给前端提供参数、返回值、错误语义和可复制示例；两条安装通道分别说明。整个 Demo 安装流程不查询 Google 商店。

前端最小路径：提前读取目录 → 用户点击调用原生安装 → 独立查询进度 → 由原回调判定结果 → 重新读取安装状态。

选择安装通道

先读取目录，再按包的 signedProduct 和目标浏览器实际提供的方法选择通道。签名安装回调只返回最终结果，下载和阶段通过独立的 getOperationProgress 查询。

随机公网域名只提供网络访问，不授予 webstorePrivate 权限。目录通道不接受 localhost、IPv6、其他 127/8 地址或其他端口。签名 Test HTTP 也不接受 loopback；普通 Chrome 没有逐风的安装能力。安装、卸载及应用更新需要真实用户点击，iframe、Worker、无痕或失效文档不可用。

网站 HTTP 接口

以下接口只读，不执行安装。无效请求返回 HTTP 状态和 text/plain 错误码；成功的目录、存活和运行状态返回 JSON。

方法与路径参数响应
GET /api/catalogplatform 可选，desktop / android / ios，默认 desktop；仅作客户端提示；all 可选 0 / 1，默认 0；各参数重复或空值非法200：{packages: Package[], errors: CatalogError[]}；all=1 返回所有有效文件，否则每 ID 一个默认包；400：invalid_platform / invalid_catalog_request
GET /api/packageid 必填；platform、file、sha256 可选；file 为目录文件名，经 URLSearchParams 编码且禁止路径分隔符；download 可选 0 / 1，默认 0；支持单段 Range 与强 ETag If-Range200：整包；206：分段 CRX；download=1 为附件保存；400：invalid_extension_id / invalid_package_request；404：package_not_found；409：package_changed；416：range_not_satisfiable
HEAD /api/package查询参数同 GET；忽略 Range200：整包头信息、Accept-Ranges 和 ETag，无包体；参数及摘要错误同 GET

桌面、Android、iOS 包统一展示，所有有效 platform 提示返回相同目录。MiVPN 保留引擎和产品元数据推导的平台标签；mivpn-ios 标记 iOS，不要求包内携带桌面或 Android 引擎。通用扩展默认三个平台提示，标签不代表已完成原生兼容性验收。只扫描 packages 第一层 *.crx，复用服务级元数据缓存。

商店使用 all=1，让每个 CRX 文件独立一行，状态和卸载仍按扩展 ID 共享。签名通道与每行“下载 CRX”使用 id + file + sha256：file 必须来自目录，不能把它直接拼进 URL 路径。指定文件不存在或不属于该 ID 返回 404，摘要变化返回 409，绝不回退其他文件。省略 file 时仍按默认最高版本选包，sha256 只锁定该默认包。普通目录通道只按 ID 取包，因此仅默认包提供安装/升级操作，其他行保留下载。不同通道安装的同 ID 不能互相接管。

curl 'http://127.0.0.1:18731/api/catalog?platform=desktop&all=1'
# 将 ID 和摘要替换为上一条目录响应的值；不直接用 file 字段拼路径。
curl -f 'http://127.0.0.1:18731/api/package?id=aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa&platform=desktop&sha256=目录返回的摘要' -o extension.crx

取包与断点续传

包响应类型为 application/x-chrome-extension。服务先以不超过 64 KiB 的读取校验整个文件的摘要，再定位同一打开文件并分块发送所需字节。原子替换不会切换已打开的下载；发送前检测到变化返回 409，发送中发现原地改写或截断会中止连接。不要把部分包体当作下载完成。

请求或响应头当前行为
Range: bytes=N-M / bytes=N- / bytes=-N支持单段闭区间、从偏移到结尾、末尾 N 字节。有效区间返回 206；结束偏移超过文件末尾时截到末尾。
Content-Range / Content-Length206 返回 bytes 起点-终点/完整大小，起止均包含；Content-Length 是本次分段长度。416 返回 bytes */完整大小，正文为 range_not_satisfiable。
Accept-Ranges: bytes / ETag200、206、416 与成功 HEAD 均提供。ETag 是用双引号包围的完整文件 SHA-256，为强校验器。
If-Range仅支持一个与当前 ETag 完全匹配的强 ETag。弱 ETag、日期值、不匹配或重复值均忽略 Range，返回整包 200；没有发送 Last-Modified。
未带 Range / 不支持的 Range整包 200；畸形、逆序、多段、重复 Range 字段或未知单位均忽略。合法但不可满足的区间（包括起点超出末尾、末尾 0 字节）返回 416。
HEAD / 未知大小模式HEAD 忽略 Range，只返回整包头、无正文。--package-without-length 只省略整包 Content-Length，206 始终带分段长度。

客户端收到 206 后，先核对 Content-Range 的起点等于本地已保存长度，再追加包体；收到 200 必须清空旧临时文件后写入整包。409 应刷新目录并重新下载。416 不能直接视为成功，须核对本地长度及完整 SHA-256。恢复完成后仍须验证整个包的摘要和签名。成功、失败、取消继续由浏览器原安装回调报告，网页不用自行下载或拼接 CRX。

GET /api/package?id=aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa HTTP/1.1
Range: bytes=262144-
If-Range: "原响应的64位SHA256"

HTTP/1.0 206 Partial Content
Content-Type: application/x-chrome-extension
Accept-Ranges: bytes
ETag: "原响应的64位SHA256"
Content-Range: bytes 262144-1048575/1048576
Content-Length: 786432

上述为 1 MiB 文件的协议示意；实际 ETag、起点与完整大小应取原下载响应和本地文件。单段范围与校验器语义参见 RFC 9110。

网页“下载 CRX”与安装取包

手动下载链接在 id、file、sha256 之外附加 download=1。200/206 及成功 HEAD 返回 application/octet-stream 和 Content-Disposition: attachment；filename 为安全 ASCII 回退名，filename* 为百分号编码的 UTF-8 原文件名，参见 RFC 6266。下载内容、ETag、摘要验证和范围续传不变，400/404/409/416 错误不附附件文件名。download 为空、重复或不为 0/1 返回 400。

正常点击后应由浏览器新增下载任务，保存 CRX 文件；网页显示“已请求下载”，不表示文件已保存完成。保存位置、下载进度和取消由浏览器下载界面管理，安装阶段条不追踪手动下载。浏览器若未接好原生下载处理，仅服务端返回 200 仍不能证明文件落盘。安装及升级传给原生 API 的 packageUrl 不带 download=1，继续返回 application/x-chrome-extension，不因手动下载入口改变。

网络约束

响应使用 no-store、nosniff 和同源 CSP；CRX 额外使用 no-transform。Host/端口及跨站子资源请求受限制，403 返回 forbidden；未开放跨域 CORS。页面、health、runtime 和静态资源不接受 query 参数。整包 CRX 可省略 Content-Length，因此下载必须支持未知总大小。

发布签名浏览器 API

命名空间 chrome.nomadSignedExtensions。install / uninstall 必须直接在点击处理函数中调用，不在它们之前 await 网络请求。callback 内读取 runtime.lastError，回调外该值可能已经被清除。

方法参数成功返回 / 语义
install(details, callback)InstallDetails，见下表{extensionId, product, version}；表示整次安装提交完成，不再调用 completeInstall
update(details, callback)（待浏览器实现）沿用 InstallDetails；用户点击，同 ID 严格更新到更高版本商店已按此合同接入；成功返回 {extensionId, product, version}。当前核对的宿主/内核未提供此方法，缺少时不显示可点击升级按钮
getStatus(extensionId, callback)32 位扩展 ID{extensionId, state, product?, version?}；state 为 absent / installed / disabled
uninstall(extensionId, callback)32 位扩展 ID；用户点击无结果值；原生确认通过后移除；取消走 lastError
getOperationProgress(operationId, callback)每次新建的非零 UUID；同一发起文档{progress?}；不需要额外点击，详见进度协议

InstallDetails

字段必填约束
extensionId是string，32 个 a–p 字符，必须与真实包身份一致
packageUrl是string，绝对 URL，必须与页面的 scheme / host / port 同源；无用户名、密码、fragment
expectedSha256否，Demo 必传string，64 位十六进制；锁定本次所选 CRX；不能代替受信发布签名
operationId否string，36 字符非零 UUID；每次操作新建，不复用；旧版没有 getter 时省略字段

下载为浏览器宿主拥有的匿名请求，不跟随重定向，不复用站点 Cookie 或凭据；当前核对的桌面安装下载器仅接受 HTTP 200，最大 128 MiB。宿主默认连接超时 10 秒、下载超时 90 秒，整个操作还有独立生命周期；网页不要用定时器把尚未结束的安装改判为失败。

状态中的 product、version 为可选字段，Demo 也容忍空值；刷新时不要求它们等于当前商店包。本次 install / update 的成功回执须与所选 ID、product、version 一致。getStatus 只描述签名安装来源中的安装状态，不报告下载进度，也不证明插件业务功能可用。当前签名状态和卸载按 ID / 安装来源筛选，不能据此推断可跨文档读取进度。

签名插件升级合同：商店已接入，浏览器与内核待实现

本轮只改商店。以下 update 是商店期待浏览器提供的合同，并非当前桌面浏览器已经可用的 API。只有 typeof chrome.nomadSignedExtensions.update === 'function' 且目录版本更高时才显示升级按钮。不会调用 uninstall 再 install，也不会把签名安装记录交给 webstorePrivate 更新。

用户点击“升级”时同步调用 update，传所选包 ID、同源 URL 与 SHA-256；提供 getter 且可生成 UUID 时同时传新的 operationId。查询结果须标记 operation: 'update'，其余 stage、receivedBytes、totalBytes? 与安装进度合同一致。下载 100% 或 completed 快照都不能代替最终回调。回调成功后核对完整回执，再读取 getStatus；状态读取失败显示“已完成升级，状态待确认”，不重发升级。没有进度 getter 时仍可升级，等待原结果回调。

层级配套要求 / 本轮状态
商店已接能力检测、版本比较、升级按钮、同源与摘要参数、独立操作进度、结果/取消/失败及状态核对；不新增 HTTP 写接口。
浏览器宿主待实现 update 分发、精确能力登记、同 ID 且更高版本的签名包校验与原生确认；绑定真实旧包快照，保留用户数据及停用状态；事务提交后才成功，失败/取消回滚旧包，防止并发、文档失效和旧候选覆盖。
内核 / KernelHost待追加 update schema、网页 feature 与精确成员、宿主能力和超时；执行当前顶层文档/来源/Profile/用户手势校验、同源包地址验证及桥接转发；进度枚举支持 update。不能只注册方法而缺少宿主实现。

宿主必须验证已安装来源与发布者身份连续性或明确的密钥轮换策略，禁止用 product 字符串或网页版本比较代替原生验证。新增权限由浏览器原生确认；签名、资源摘要、CRX 身份、DNR 和平台兼容性检查继续执行。错误通过 update 的原 callback 内 runtime.lastError 返回；商店保留错误码。没有接口、同版、已安装版更新或版本未知时均不触发升级。

// 待浏览器提供 update 后可用；必须在真实用户点击中同步调用。
const api = window.chrome?.nomadSignedExtensions;
if (typeof api?.update !== 'function') {
  throw new Error('当前浏览器尚不支持签名插件原地升级');
}
const url = new URL('/api/package', location.origin);
url.searchParams.set('id', item.id);
url.searchParams.set('file', item.file);
url.searchParams.set('sha256', item.sha256);
api.update({ extensionId: item.id, packageUrl: url.href,
  expectedSha256: item.sha256 }, result => {
  const error = chrome.runtime.lastError;
  if (error) return showError(error.message); // 含失败与取消；不自动卸载。
  if (result?.extensionId !== item.id || result.product !== item.signedProduct ||
      result.version !== item.version) return showError('升级回执与所选插件不一致');
  refreshStatus(); // 实际 Demo 还会核对 getStatus 后再显示成功。
});

本机目录浏览器 API

命名空间为 chrome.webstorePrivate 与受商店授权的 chrome.management。调用来源须满足目录商店规则；以下只描述本 Demo，Edge 官方商店内部完成提交的兼容分支不适用于此流程。

方法参数结果与调用边界
beginInstallWithManifest3(details, callback){id, manifest, localizedName?, operationId?}；manifest 是 JSON 字符串成功返回空字符串；取包、校验和用户批准已完成，仍须 completeInstall；非空字符串是业务结果码
completeInstall(id, callback)与前一步相同 ID无值且无 lastError 表示提交成功；同 Profile / Origin / Document 的一次性批准，约三分钟有效；无需第二次点击
getOperationProgress(operationId, callback)36 字符非零 UUID{progress?}；新装使用 install，检查更新使用 update_check
getExtensionStatus(id, manifest?, callback)ID；可选 manifest JSON 字符串常见返回 enabled / disabled / installable / deprecated_manifest_version；Demo 状态展示主要使用 getAll
management.getAll(callback)无扩展数组；Demo 按 id、type=extension、version、enabled 建立状态表
management.uninstall(id, options, callback){showConfirmDialog: true}；用户点击无值且无 lastError 表示移除；传 false 也不能绕过原生确认
checkUpdate(id, options?, callback){operationId?}；可保持旧形式 id, callback{state, version, errorCode}；只准备候选包，不等于已应用
applyUpdate(id, callback)用户的另一次点击boolean；true 才表示已应用。false 可能是取消、延期、候选包变化，不能统一显示成功

manifest 必须与实际包的版本、MV、权限、可选权限、host 权限、内容脚本匹配等关键声明一致；仅替换 localizedName 不改变包身份或授权。beginInstall 的完整 manifest 参数预算为 1,048,576 个字符。宿主固定从当前商店 origin 的 /api/package?id=... 取包，目录更新从 /api/catalog 取候选；网页不能通过 details 指定另一个下载地址。

历史 127.0.0.1 目录来源保留原管理范围；新增局域网目录来源只枚举、管理和更新自身安装来源。不能根据页面按钮的旧状态推断已安装，目录或状态读取失败后应关闭相关操作，刷新成功再恢复。

进度字段与生命周期

每次操作创建新 UUID，调用原生安装之后才启动查询。每次查询返回后等待约 300 毫秒，避免重叠请求；原结果回调到达时停止。查询失败只关闭进度读取，安装仍等待原回调。当前前端应优先使用 operationId，避免依赖按扩展 ID 查最新任务的候选扩展。

    "operation": "install",
    "extensionId": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
    "stage": "downloading",
    "receivedBytes": 524288,
    "totalBytes": 1048576
  }
}

operationId / operation / extensionIdstring必须同时关联本次任务；现有安装为 install、目录检查为 update_check；待浏览器实现的签名升级须为 update
stagestring见下表；轮询可能跳过短暂阶段，未知值显示通用处理中

下载 100% 只代表包体接收完成。不要给校验和安装分配固定的 65% / 90%，也不要把标签页导航加载条当作 CRX 进度。总大小未知时显示下载动画和已接收大小；用户取消、失败、成功继续走原回调。

前端接入示例

先复制公共辅助函数，再选择当前通道示例。辅助函数没有依赖 Demo 的 app.js，不新增浏览器接口；它们保留原生点击时机、同次任务关联、未知大小显示和轮询清理。示例结果交给业务 UI 展示，失败后不要无条件自动重装。

公共辅助函数
function callBrowser(api, method, ...args) {
  return new Promise((resolve, reject) => {
    try {
      api[method](...args, result => {
        const error = window.chrome?.runtime?.lastError;
        if (error) reject(new Error(error.message));
        else resolve(result);
      });
    } catch (error) { reject(error); }
  });
}

// 仅用于状态和进度读取；安装、卸载、应用升级不用网页超时替代原回调。
async function readBrowser(api, method, ...args) {
  let timer;
  try {
    return await Promise.race([
      callBrowser(api, method, ...args),
      new Promise((_, reject) => {
        timer = setTimeout(() => reject(new Error('状态读取超时')), 15000);
      })
    ]);
  } finally { clearTimeout(timer); }
}

function currentClientPlatform() {
  const agent = window.navigator?.userAgent || '';
  if (/iPad|iPhone|iPod/i.test(agent) ||
      /Macintosh/i.test(agent) && (window.navigator?.maxTouchPoints || 0) > 1) return 'ios';
  return /Android/i.test(agent) ? 'android' : 'desktop';
}

function newOperationId() {
  const crypto = window.crypto;
  if (typeof crypto?.randomUUID === 'function') return crypto.randomUUID();
  if (typeof crypto?.getRandomValues !== 'function') return null;
  // 局域网 HTTP 通常没有 randomUUID，但仍提供 getRandomValues。
  const bytes = crypto.getRandomValues(new Uint8Array(16));
  bytes[6] = (bytes[6] & 15) | 64;
  bytes[8] = (bytes[8] & 63) | 128;
  const hex = Array.from(bytes, b => b.toString(16).padStart(2, '0')).join('');
  return `${hex.slice(0, 8)}-${hex.slice(8, 12)}-${hex.slice(12, 16)}-${hex.slice(16, 20)}-${hex.slice(20)}`;
}

// 在原安装调用已经发出后启动；返回停止函数。这是示例 helper，不是浏览器事件 API。
function watchProgress(api, item, operationId, operation, onProgress = () => {},
                       onUnavailable = () => {}) {
  if (!operationId || typeof api?.getOperationProgress !== 'function') return () => {};
  let active = true;
  let timer = setTimeout(poll, 0);
  function stop() { active = false; clearTimeout(timer); }
  async function poll() {
    try {
      const result = await readBrowser(api, 'getOperationProgress', operationId);
      if (!active) return;
      const p = result?.progress;
      if (p?.operationId === operationId && p.extensionId === item.id && p.operation === operation)
        onProgress(p); // 未知 stage 保留原值，交给界面显示通用等待提示。
      if (active) timer = setTimeout(poll, 300);
    } catch (error) {
      if (active) { stop(); onUnavailable(error); } // 不拒绝原安装 Promise。
    }
  }
  return stop;
}

function progressText(p) {
  if (p.stage === 'downloading') {
    if (!Number.isFinite(p.receivedBytes) || p.receivedBytes < 0) return '正在下载，等待字节数据';
    const received = p.receivedBytes.toLocaleString() + ' B';
    if (!Number.isFinite(p.totalBytes) || p.totalBytes <= 0) return '正在下载，已接收 ' + received;
    const percent = Math.min(100, Math.floor(p.receivedBytes / p.totalBytes * 100));
    return `正在下载 ${received} / ${p.totalBytes.toLocaleString()} B · ${percent}%`;
  }
  const labels = {
    preparing: '准备取包', verifying: '正在校验', preflight: '检查兼容性和权限',
    opening_confirmation: '正在打开权限窗口', awaiting_user_confirmation: '等待用户确认',
    awaiting_install: '已获批准，等待提交安装', // 较新宿主的可选阶段。
    installing: '正在安装', committing: '正在确认安装结果', rolling_back: '正在回滚',
    completed: '浏览器报告完成，等待核对最终回调', failed: '等待失败结果回调',
    cancelled: '等待取消结果回调'
  };
  return labels[p.stage] || '浏览器正在处理';
}

async function refreshManagedResult(action) {
  try {
    const items = await readBrowser(window.chrome.management, 'getAll');
    if (!Array.isArray(items)) throw new Error('扩展列表格式无效');
    return { items, statusWarning: null };
  } catch (error) {
    return { items: null, statusWarning: action + '，状态待刷新确认：' + error.message };
  }
}

function validateSignedStatus(item, status) {
  if (!status || status.extensionId !== item.id || !['absent', 'installed', 'disabled'].includes(status.state))
    throw new Error('浏览器安装状态无效');
  for (const field of ['product', 'version']) {
    if (status[field] != null && typeof status[field] !== 'string') throw new Error(field + ' 类型无效');
  }
  return status;
}
签名安装及成功后状态复核
async function installSigned(item, onProgress, onProgressUnavailable) {
  const api = window.chrome?.nomadSignedExtensions;
  if (!item.signedProduct || !['install', 'getStatus', 'uninstall'].every(k => typeof api?.[k] === 'function'))
    throw new Error('当前插件或浏览器不支持签名安装');
  const operationId = typeof api.getOperationProgress === 'function' ? newOperationId() : null;
  const url = new URL('/api/package', window.location.origin);
  url.searchParams.set('id', item.id);
  url.searchParams.set('file', item.file);
  url.searchParams.set('platform', currentClientPlatform());
  url.searchParams.set('sha256', item.sha256);

  // Promise executor 同步调用原生 API，前面没有 await，保留真实点击激活。
  const pending = callBrowser(api, 'install', {
    extensionId: item.id, packageUrl: url.href, expectedSha256: item.sha256,
    ...(operationId && { operationId })
  });
  const stop = watchProgress(api, item, operationId, 'install', onProgress, onProgressUnavailable);
  let receipt;
  try { receipt = await pending; }
  finally { stop(); }
  if (receipt?.extensionId !== item.id || receipt.product !== item.signedProduct || receipt.version !== item.version)
    throw new Error('安装回执与所选插件不一致，请刷新确认状态');

  // 原生成功之后的状态查询失败，不改报成“安装失败”，也不自动再次安装。
  try {
    const status = validateSignedStatus(item, await readBrowser(api, 'getStatus', item.id));
    if (!['installed', 'disabled'].includes(status.state) ||
        status.product != null && status.product !== item.signedProduct ||
        status.version != null && status.version !== item.version)
      throw new Error('安装状态与本次安装尚未一致');
    return { receipt, status, statusWarning: null };
  } catch (error) {
    return { receipt, status: null, statusWarning: '浏览器已完成安装，状态待确认：' + error.message };
  }
}
目录新装及 completeInstall
async function installCatalog(item, onProgress, onProgressUnavailable) {
  const api = window.chrome?.webstorePrivate;
  if (!['beginInstallWithManifest3', 'completeInstall'].every(k => typeof api?.[k] === 'function') ||
      typeof window.chrome?.management?.getAll !== 'function')
    throw new Error('当前页面没有目录安装权限');
  const operationId = typeof api.getOperationProgress === 'function' ? newOperationId() : null;
  const pending = callBrowser(api, 'beginInstallWithManifest3', {
    id: item.id, manifest: JSON.stringify(item.manifest), localizedName: item.name,
    ...(operationId && { operationId })
  });
  const stop = watchProgress(api, item, operationId, 'install', onProgress, onProgressUnavailable);
  let approved;
  try { approved = await pending; }
  finally { stop(); } // 兼容旧宿主：begin 的任务可能已被删除。
  if (approved !== '') throw new Error(approved || 'install_failed');
  // 此时仅表示批准成功。无需第二次点击，在同一文档立即提交。
  await callBrowser(api, 'completeInstall', item.id);
  return refreshManagedResult('浏览器已完成安装');
}
目录更新检查及应用
async function prepareCatalogUpdate(item, onProgress, onProgressUnavailable) {
  const api = window.chrome?.webstorePrivate;
  if (typeof api?.checkUpdate !== 'function') throw new Error('当前通道不支持检查更新');
  const operationId = typeof api.getOperationProgress === 'function' ? newOperationId() : null;
  const options = operationId ? [{ operationId }] : []; // 旧浏览器不传新增参数。
  const pending = callBrowser(api, 'checkUpdate', item.id, ...options);
  const stop = watchProgress(api, item, operationId, 'update_check', onProgress, onProgressUnavailable);
  try {
    const result = await pending;
    if (!['ready', 'permission_required'].includes(result?.state))
      return { ready: false, result }; // up_to_date、throttled、error 等各自展示。
    if (result.version !== item.version) throw new Error('目录版本已变化，请刷新后重新准备');
    return { ready: true, version: result.version, sha256: item.sha256 };
  } finally { stop(); }
}

// 由另一次用户点击直接调用；不要在 prepare 的回调中自动调用。
async function applyCatalogUpdate(item, prepared) {
  const api = window.chrome?.webstorePrivate;
  if (typeof api?.applyUpdate !== 'function') throw new Error('当前通道不支持应用更新');
  if (!prepared?.ready || prepared.version !== item.version || prepared.sha256 !== item.sha256)
    throw new Error('候选包已变化，请重新准备');
  const applied = await callBrowser(api, 'applyUpdate', item.id);
  if (applied !== true) throw new Error('升级尚未应用，可能取消、延期或候选包已失效');
  return refreshManagedResult('浏览器已完成操作');
}

预加载目录并绑定安装按钮
// 约定页面有 #install 按钮和 #install-status 文本区域。
// 先加载目录，用户点击时只读取已经准备好的 item，不在点击回调中先取包。
async function bindSignedInstall() {
  const button = document.querySelector('#install');
  const output = document.querySelector('#install-status');
  button.disabled = true;
  const platform = currentClientPlatform();
  const response = await fetch('/api/catalog?platform=' + platform, { cache: 'no-store' });
  if (!response.ok) throw new Error('目录 HTTP ' + response.status);
  const { packages } = await response.json();
  const item = packages.find(item => item.signedProduct); // 实际商店改为用户选中的目录项。
  if (!item) throw new Error('目录没有签名插件');
  button.textContent = '安装 ' + item.name;
  button.disabled = false;
  button.addEventListener('click', () => {
    button.disabled = true;
    output.textContent = '等待浏览器响应';
    installSigned(item, p => { output.textContent = progressText(p); },
      error => { output.textContent = '进度暂不可用，安装仍在继续：' + error.message; })
      .then(result => { output.textContent = result.statusWarning || '安装成功'; })
      .catch(error => { output.textContent = '安装未完成：' + error.message; })
      .finally(() => { button.disabled = false; });
  });
}

结果回调与错误处理

三类结果分开处理：runtime.lastError 是浏览器异步错误；beginInstall 的非空字符串是业务结果；checkUpdate 的 state/errorCode 是更新状态。成功回调到达后再刷新状态；进度事件或网络完成不能替代它。

返回值或错误码含义处理
beginInstall 返回空字符串验证和权限批准完成同文档调用 completeInstall，尚不显示安装成功
user_gesture_required / signed_extension_user_gesture_required缺少实时点击激活将原生入口放到点击回调，之前不 await 网络
already_installed / signed_extension_already_installed目标 ID 已存在刷新状态；不要自动卸载或重试安装
install_in_progress / signed_extension_install_in_progress已有事务正在执行禁用重复操作，等待原任务结果
user_cancelled / signed_extension_confirmation_cancelled / signed_extension_operation_cancelled用户、文档或生命周期取消恢复操作；不伪造成功，不自动再次弹权限窗口
signed_extension_document_unavailable / webstore_document_unavailable发起页面刷新、关闭或文档身份失效新页面重新读取安装状态，不能恢复旧 UUID 或安装批准
webstore_previous_confirmation_required / webstore_confirmation_expiredcompleteInstall 没有本次有效批准或批准已消费不要独立重试 completeInstall；先刷新状态，再由用户决定重新开始
signed_extension_download_failed / webstore_download_failed网络失败或响应不满足取包要求检查同源包地址、HTTP 状态及浏览器诊断；保留原错误码
webstore_arguments_invalid参数或旧版 UUID 校验失败按参数类型传值，使用非零 UUID，不用扩展 ID 替代稳定查询参数
manifest_error页面清单预览与实际包不一致刷新目录并重新选择候选
signed_extension_host_unavailable当前精确宿主能力没有登记或实际运行包不配套核对内核、KernelHost、Foundation 和 UI 宿主版本
signed_extension_download_url_invalid来源、同源、URL 形式不满足要求检查 scheme/host/port 及 URL 用户信息、fragment
signed_extension_package_hash_mismatch / HTTP 409 package_changed目录摘要或下载文件已经变化刷新目录，禁止把旧候选当作本次包继续安装
signed_extension_signature_invalid / webstore_package_invalid发布签名或 CRX/身份/包结构校验失败保留原始码并查浏览器安装阶段日志；signedProduct 不是验签结果
crx_native_stage_failed暂存阶段通用失败查安装器详细诊断，不能直接归因于签名或 DNR
dnr_package_invalidDNR 校验失败不凭目录扫描断言内核缺能力
dnr_kernel_capability_unavailable明确缺少所需 DNR 能力提示换用兼容内核
operation_id_invalid / operation_id_in_use 类错误UUID 非法、全零或重复每次点击生成新的非零 UUID；不要传 null 字段
成功回执后状态读取失败安装可能已经完成显示已完成但状态待确认，提供刷新入口；不要改判为普通下载失败

目录通道常见诊断消息为中文加末尾括号码，例如 扩展程序包校验失败。 (webstore_package_invalid)；可按末尾 ([a-z][a-z0-9_]+) 提取稳定码。签名通道通常直接返回 signed_extension_*。显示未知错误时保留 message，避免把所有失败都改成“下载失败”。卸载取消也可能是 User cancelled uninstall。

部分较新宿主源码包含持续安装任务、内部自动 UUID、按扩展 ID 查询最新任务和 awaiting_install；本次核对的签名网页内核查询门禁仍要求 36 字符 UUID。不要将宿主能解析某字段等同于目标网页已经可用。目录终态保留和 completeInstall 全过程查询也需要与内核 schema、宿主交付及网页接线同时核对，不能只换其中一层。

本 Demo 当前在 beginInstall 回调后停止该轮进度，并根据 completeInstall 调用边界显示安装；checkUpdate 只展示候选准备。本文保留这一兼容调用方式，较新宿主可返回更多阶段，未知阶段应显示通用等待文本。

限速在约八个包体位置等待，保持流式读取；已知与未知总大小都应测。当前没有 --no-package-without-length 反向参数，正式测试配置应与日常实例隔离。非 18731 端口只适合 HTTP 或符合签名通道来源规则的测试，不获得本机目录授权。
