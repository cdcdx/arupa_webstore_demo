补充说明：
- `✅` 表示支持，`❌` 表示不支持。
- `identity` API 整体支持桌面和 Android，但 `identity.getAccounts`、`identity.getAuthToken` 两个方法在 Edge 中均不支持。
- `identity.getAuthToken` 的替代方案是 `identity.launchWebAuthFlow`。
- `browserAction` 和 `pageAction` 只有 MV2。
