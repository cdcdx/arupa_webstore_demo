## 自建商店 API 能力

- MV能力差异：桌面 62+项能力 / 安卓 29+项能力
- 自建商店 https://webstore.zfbrowser.com
    - 商店页推荐逻辑
      - 桌面推荐应用
      - 安卓推荐应用
      - 广告推荐应用
    - Desktop：商店页 → 受限 `webstorePrivate` → 浏览器原生下载、校验、确认、安装。
    - Android：公开商店负责浏览，安装跳转 `nomad://extensions` 内部 Hub → Mojo/JNI → 兼容检查 → 原生下载与授权。
        - 严格区分 `可搜索 / 可安装 / 推荐 / 已验证`，避免复刻 Edge 中搜索结果与移动端推荐列表混用的问题。
        - Android 首期建议 CRX3 + MV3-only。
    - Nomad应用来源+更新：
      - 前期爬虫为主：从 谷歌应用商店/edge扩展商店 拉取一定基数的主流应用；
      - 自有审核为辅：可以手动添加应用，并可配置原始 谷歌商店/edge商店 链接；
      - 应用同步频率：每周更新一次，随机更新，保障每个应用每7天更新一次；
    - CRX使用版本化不可变地址；
      - 不可变地址和 谷歌商店/edge商店 保持一致；
      - 签名、ID、SHA-256、包内 manifest、权限和平台能力全部由浏览器进程重新验证；
